# DSA Forge

DSA Forge is a modern, interactive web platform dedicated to empowering students and developers with high-quality education in Data Structures and Algorithms (DSA), Low Level Design (LLD), Object-Oriented Programming (OOPS), and comprehensive interview preparation.

Built with a state-of-the-art tech stack and a stunning glassmorphic UI, DSA Forge offers an immersive learning experience.

## Features

- **Modern Glassmorphism UI**: A sleek, futuristic dark-mode design with glowing gold accents and a dynamic "Soft Aurora" background.
- **Fluid Animations**: Smooth page transitions and interactive hover effects powered by Framer Motion.
- **Responsive Design**: Fully optimized for both desktop and mobile viewing experiences.
- **Comprehensive Curriculum**: Structured courses covering everything from basic DSA to advanced system design.
- **Masterclasses & Mentorship**: Access to industry experts, live masterclasses, and a vibrant community of learners.

## Tech Stack

- **Framework**: [React 19](https://react.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Build Tool**: [Vite 6](https://vitejs.dev/)
- **Styling**: Vanilla CSS with modern flexbox/grid layouts and CSS variables.
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Routing**: [React Router DOM](https://reactrouter.com/)
